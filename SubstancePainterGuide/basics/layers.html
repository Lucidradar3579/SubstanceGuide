Understanding Layers in Substance 3D Painter

Difficulty: Beginner Time: 25 minutes Software: Substance 3D Painter Roblox Relevance: Fundamental

Layers are the foundation of Substance 3D Painter's non-destructive workflow. Understanding how layers work is essential for creating complex, editable materials for your Roblox assets. This guide covers all layer types, their properties, and how to use them effectively.

Why Layers Matter for Roblox Workflows

Mastering layers allows you to create complex materials that are easy to modify, iterate on, and reuse across different Roblox projects. Non-destructive workflow means you can always go back and adjust without starting over.

The Layer Stack Concept

Before diving into specific layer types, understand how the layer stack works:

How the Layer Stack Works:

  • Layers are composited from bottom to top
  • Each layer can affect one or more channels (Base Color, Roughness, Metalness, Normal, Height)
  • Blending modes determine how layers interact with layers below
  • Masks control where each layer is visible
  • Layers can be grouped for organization
  • Roblox Tip: Think of each layer as adding a specific characteristic to your material

Channels Explained

Substance 3D Painter works with these texture channels:

Base Color

The actual color of your material (Albedo)

Roblox: Maps to SurfaceAppearance.ColorMap

Color Space: sRGB

Roughness

How smooth or rough the surface is

Roblox: Maps to SurfaceAppearance.RoughnessMap

Value: 0 = smooth, 1 = rough

Color Space: Linear

Metalness

Whether the surface is metallic or not

Roblox: Maps to SurfaceAppearance.MetalnessMap

Value: 0 = non-metal, 1 = metal

Color Space: Linear

Normal

Surface detail for lighting simulation

Roblox: Maps to SurfaceAppearance.NormalMap

Format: OpenGL (Y inverted for DirectX)

Color Space: Linear

Height

Surface displacement (for parallax effects)

Roblox: Not directly used, but useful for baking

Color Space: Linear

Ambient Occlusion

Contact shadowing in crevices

Roblox: Can be used in ColorMap or as separate map

Color Space: Linear

Layer Types Overview

Substance 3D Painter offers several layer types, each serving different purposes:

Fill Layers

Uniform content across the entire texture set:

  • Solid colors, gradients, or procedural patterns
  • Infinitely editable and resolution independent
  • Great for base material properties
  • Roblox Use: Setting base PBR values (color, roughness, metalness)

Paint Layers

Hand-painted or projected content:

  • Brush-based painting in 2D or 3D view
  • Projection through camera or stencils
  • Clone, heal, and other painting tools
  • Roblox Use: Adding unique details, wear, dirt, or character-specific markings

Layer Groups

Organizational containers for layers:

  • Group related layers (e.g., all "wear" layers)
  • Apply masks and effects to entire groups
  • Collapse/export for cleaner layer stack
  • Roblox Use: Organizing complex materials by component or effect type

Fill Layers Deep Dive

The most versatile layer type for base material setup:

Fill Layer Properties

What you can control in a Fill Layer:

Content Type

What the layer fills with:

  • Solid Color
  • Gradient (linear, radial, angular)
  • Noise (various types: Gaussian, etc.)
  • Patterns (bricks, tiles, etc.)
  • From Mesh (baked curvature, position, etc.)

Channels

Which texture channels to affect:

  • Base Color (RGB)
  • Roughness (Grayscale)
  • Metalness (Grayscale)
  • Normal (RGB - usually from generator)
  • Height (Grayscale)
  • Ambient Occlusion (Grayscale)
  • Tip: You can enable/disable channels independently

Blending and Opacity

How the layer combines with layers below:

  • Blending Mode (Normal, Multiply, Overlay, etc.)
  • Opacity (0-100%)
  • Flow (for brush-like buildup)
  • Per-channel blending modes (advanced)

Practical Fill Layer Examples for Roblox

Common uses in Roblox texturing workflows:

Setting Up Basic PBR Properties

1

Base Color Fill Layer

Create your foundation color:

  • Add Fill Layer
  • Set Content to "Color"
  • Choose your base color (e.g., #8B4513 for wood)
  • Enable only Base Color channel
  • Set blending to "Normal"
  • Name: "Base Color - Wood"

2

Roughness Fill Layer

Define surface smoothness:

  • Add Fill Layer
  • Set Content to "Color" (grayscale)
  • Set value (0.3 for moderately smooth wood)
  • Enable only Roughness channel
  • Set blending to "Normal"
  • Name: "Roughness - Wood"

3

Metalness Fill Layer

Define metallic properties:

  • Add Fill Layer
  • Set Content to "Color" (grayscale)
  • Set value (0.0 for wood)
  • Enable only Metalness channel
  • Set blending to "Normal"
  • Name: "Metalness - Wood"

Pro Tip: Using Gradients in Fill Layers

Gradients are powerful for creating variety:

  • Linear gradients for directional variation
  • Radial gradients for falloff from center
  • Angular gradients for rotational patterns
  • Roblox Example: Use radial gradient in roughness to create worn centers on wheels or handles

Paint Layers Deep Dive

For when you need hand-crafted details:

Paint Layer Properties

What makes Paint Layers unique:

Painting Tools

Different ways to apply paint:

  • Brush Tool - Freehand painting
  • Eraser Tool - Removing paint
  • Clone Tool - Copying from one area to another
  • Heal Tool - Blending copied content
  • Shape Tool - Drawing geometric shapes
  • Text Tool - Adding text

Brush Settings

Control your brush behavior:

  • Size - Brush diameter
  • Hardness - Edge softness
  • Flow - Paint buildup rate
  • Spacing - Distance between paint dots
  • Rotation - Brush angle
  • Scatter - Random position variation

Projection Modes

How paint gets applied to 3D models:

  • View Projected - Through camera view
  • UV Projected - Through UV space
  • Normal Projected - Along surface normals
  • Stencil Projected - Through a stencil mask

Practical Paint Layer Examples for Roblox

Common uses in Roblox texturing workflows:

Adding Character Details

1

Painting Wear and Scratches

Add realistic use patterns:

  • Add Paint Layer
  • Choose a scratch or wear brush
  • Set color to slightly lighter/darker than base
  • Paint in areas that would naturally wear
  • Use pressure sensitivity for variation
  • Tip: Use low flow (10-30%) for subtle buildup

2

Adding Unique Markings

Create character-specific details:

  • Add Paint Layer
  • Choose appropriate color
  • Use stencils for logos, numbers, or symbols
  • Or freehand paint for unique designs
  • Consider placement for visibility in-game
  • Tip: Use layers to easily toggle markings on/off

3

Projection Painting for Precision

Apply details with accurate positioning:

  • Add Paint Layer
  • Switch to "View Projected" mode
  • Position your camera for desired angle
  • Paint - strokes will follow camera perspective
  • Great for applying decals or labels
  • Roblox Tip: Use for applying Roblox logos or brand elements

Layer Groups and Organization

Keeping your layer stack manageable:

When to Use Layer Groups:

  • Organizing by material type (wood, metal, plastic)
  • Grouping by effect type (base, details, wear, dirt)
  • Creating variations (different color schemes)
  • Preparing for export (group layers you want to toggle)

Creating and Using Layer Groups

1

Creating a Layer Group

Organize related layers:

  • Select layers to group (Shift+Click)
  • Right-click > "Group Layers"
  • Or press Ctrl+G (Cmd+G on Mac)
  • Name your group descriptively
  • Example: "Wood Material" group containing base color, roughness, etc.

2

Group Properties

Control the group as a unit:

  • Group blending mode affects all layers inside
  • Group opacity affects all layers inside
  • Group mask affects visibility of all layers inside
  • You can still edit individual layers inside
3

Practical Grouping Examples

Common grouping strategies for Roblox:

  • Material Groups: Separate groups for wood, metal, fabric, etc.
  • Effect Groups: Base, Details, Wear, Dirt, etc.
  • Variation Groups: Different color schemes or weather states
  • Roblox Specific: Groups for different LOD levels or platforms

Advanced Layer Techniques

Power-user features for complex materials:

Blending Modes Deep Dive

Understanding how layers combine:

Most Useful Blending Modes for Roblox:

Normal

Standard alpha blending

Use for: Most layers, base colors

Multiply

Darkens based on layer values

Use for: Dirt, grime, shadows, stains

Overlay

Enhances contrast

Use for: Wear, scratches, surface detail

Screen

Lightens based on layer values

Use for: Scratches, highlights, dust

Add (Linear Dodge)

Adds values together

Use for: Emissive effects, light leaks

Color Dodge

Brightens to reflect layer color

Use for: Intense highlights, sparkling effects

Tip: Experiment with blending modes to discover unique effects!

Per-Channel Blending

Different blending modes per channel:

Advanced but powerful for precise control:

  • Set different blending for Base Color vs Roughness vs Metalness
  • Example: Overlay for Base Color detail, Multiply for Roughness variation
  • Roblox Use: Create complex material variations while maintaining physical accuracy

Pro Tip: Create Layer Templates

Save time on repetitive setups:

  • Create a layer setup you use frequently (e.g., basic PWR material)
  • Right-click on the layer group > "Create Smart Material"
  • Name it and save to your shelf
  • Now you can drag-and-drop this setup onto any project
  • Example: Create a "Roblox Base PBR" smart material with color, roughness, and metalness fill layers
