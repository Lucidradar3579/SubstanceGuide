Understanding Generators in Substance 3D Painter

Difficulty: Beginner → Intermediate Time: 30 minutes Software: Substance 3D Painter Roblox Relevance: High

Generators are procedural algorithms that create textures and patterns based on your mesh's geometry. They are the engines behind Smart Materials and intelligent masking, allowing you to create complex, adaptive details that automatically respond to your model's shape. This guide covers all major generator types and how to use them effectively for Roblox asset creation.

Why Generators Matter for Roblox Workflows

Generators allow you to create details that automatically adapt to your mesh - wear on edges, dirt in crevices, scratches on high-contact areas - without manual painting. This saves tremendous time and ensures consistency across similar assets.

Generator Fundamentals

Understanding how generators work:

How Generators Work:

  • Generators analyze your mesh geometry (curvature, position, normals, etc.)
  • They create procedural textures based on this analysis
  • Output is typically grayscale values suitable for masks
  • Can be used in Fill Layers, Paint Layers, or to drive masks
  • Roblox Tip: Think of generators as "smart brushes" that know where to apply effects based on your model's shape

Generator Categories:

Geometry-Based

Based on mesh shape and topology

  • Curvature - Edge and corner detection
  • Position - Height and depth information
  • Normal - Surface orientation
  • Ambient Occlusion - Light occlusion in crevices
  • Thickness - Mesh thickness variation

Noise-Based

Procedural noise patterns

  • Gaussian Noise - Classic grain
  • Perlin Noise - Organic patterns
  • Simplex Noise - Efficient Perlin alternative
  • White Noise - Random values
  • Crackle Noise - Cracked surface patterns

Pattern-Based

Structured patterns and designs

  • Grids - Lines and intersections
  • Bricks - Masonry patterns
  • Tiles - Regular repeating patterns
  • Circles - Radial and circular patterns
  • Shapes - Geometric shapes (triangles, hexagons, etc.)

Filter-Based

Modified versions of other maps

  • Blur - Smoothing
  • Sharpen - Edge enhancement
  • Gradient - Directional changes
  • Histogram - Value remapping
  • Levels - Contrast and brightness

Special Purpose

Unique and specialized generators

  • From Mesh - Use existing texture maps
  • User Grayscale - Import custom masks
  • Color to Grayscale - Convert color information
  • Interpolate - Blend between two inputs
  • Histogram Scan - Advanced value analysis

Geometry-Based Generators

The most useful generators for intelligent, adaptive detailing:

Curvature Generator

Detects edges, corners, and crevices:

Curvature Types:

  • Mean Curvature: Average of all curvatures (best for wear detection)
  • Gaussian Curvature: Product of curvatures (good for sharp corners)
  • Maximum Curvature: Highest curvature value
  • Minimum Curvature: Lowest curvature value

Parameters:

  • Type: Which curvature algorithm to use
  • Distance: How far to sample for curvature calculation
  • Balance: Shift the output range (0-1)
  • Contrast: Increase difference between high and low values
  • Roblox Use: Edge wear, scratches, paint chipping on corners and edges

Position Generator

Based on vertex height/depth:

Position Modes:

  • Absolute: Actual world position
  • Relative: Position within object's bounding box
  • Normalized: 0-1 range within object

Parameters:

  • Axis: X, Y, or Z axis to measure
  • Direction: Positive or negative direction
  • Tolerance: How strict the selection is
  • Blur: Soften the transition
  • Roblox Use: Dirt in crevices (low points), wear on high points, snow accumulation

Ambient Occlusion Generator

Simulates light occlusion in crevices:

AO Types:

  • Ray-Based: Accurate but slower
  • Vertex-Based: Faster approximation
  • Multi-Bounce: Multiple light bounces for realism

Parameters:

  • Distance: Max ray distance for occlusion check
  • Subdivision: Mesh subdivision for quality
  • Spread: How far AO influence spreads
  • Substance: How much to darken occluded areas
  • Roblox Use: Dirt, grime, moss in corners, joints, and enclosed areas

Normal Generator

Based on surface normal direction:

Parameters:

  • Axis: X, Y, or Z component to isolate
  • Direction: Positive or negative direction
  • Tolerance: How close to axis to consider
  • Roblox Use: Isolating tops of surfaces (water accumulation), sides (directional wear)

Thickness Generator

Based on mesh thickness:

Parameters:

  • Mode: Absolute or relative thickness
  • Invert: Thin vs thick areas
  • Blur: Soften transitions
  • Roblox Use: Edge highlighting on thin materials, wear pattern variation

Noise-Based Generators

Creating organic, random patterns:

Gaussian Noise

Classic statistical noise:

Parameters:

  • Balance: Shift the range (0-1)
  • Contrast: Increase difference between values
  • Scale: Size of noise features
  • Roblox Use: Base noise for materials, variation in uniform surfaces

Perlin and Simplex Noise

Organic, coherent noise patterns:

Parameters:

  • Scale: Size of noise features
  • Offset: Move the noise pattern
  • Octaves: Complexity (more = more detail)
  • Persistence: How much each octave contributes
  • Roblox Use: Organic textures like stone, wood grain, fabric

Crackle Noise

Creates cracked surface patterns:

Parameters:

  • Scale: Size of crack features
  • Stretch: Distort the pattern
  • Offset: Move the pattern
  • Relaxation: How much to smooth cracks
  • Roblox Use: Dry earth, cracked paint, aged ceramics

White Noise

Pure random values:

Parameters:

  • Scale: Size of noise features
  • Offset: Move the pattern
  • Roblox Use: Television static, certain metal finishes, deliberate randomness

Pattern-Based Generators

Creating structured, repeating patterns:

Grid Generator

Creates intersecting lines:

Parameters:

  • Scale: Size of grid cells
  • Offset: Move the grid pattern
  • Angle: Rotate the grid
  • Thickness: Width of grid lines
  • Roblox Use: Technical surfaces, flooring, industrial designs

Bricks Generator

Creates masonry patterns:

Parameters:

  • Scale: Size of bricks
  • Offset: Move the pattern
  • Angle: Rotate the pattern
  • Row Offset: Stagger rows (brick bond)
  • Mortar Size: Width of mortar lines
  • Roblox Use: Walls, floors, paths, construction elements

Tiles Generator

Creates regular repeating patterns:

Parameters:

  • Scale: Size of tiles
  • Offset: Move the pattern
  • Angle: Rotate the pattern
  • Aspect Ratio: Width to height ratio
  • Roblox Use: Bathroom tiles, kitchen backsplashes, flooring

Circles Generator

Creates radial and circular patterns:

Parameters:

  • Scale: Size of circles
  • Offset: Move the pattern
  • Angle: Rotate the pattern
  • Thickness: Width of circle lines
  • Fill: Solid circles vs outlines
  • Roblox Use: Dials, gauges, decorative elements, mechanical parts

Practical Generator Examples for Roblox

Real-world examples of how to use generators effectively:

Metal Material Examples

Creating realistic metal materials:

Brushed Metal

1

Directional Brushing Effect

Create brushed metal appearance:

  • Add Fill Layer for roughness variation
  • Set content to "Gradient" generator
  • Set gradient to Linear
  • Set angle to desired brushing direction (e.g., 0° for horizontal)
  • Adjust balance and contrast for subtle effect
  • Roblox Tip: Use low contrast (10-20%) for subtle brushing

2

Adding Edge Wear

Where metal shows use:

  • Add Fill Layer for wear (lighter metal)
  • Add Black Mask
  • Generate mask using Curvature (Mean Curvature)
  • Adjust balance and contrast for edge detection
  • Optionally add Noise to mask for variation
  • Set blending to Normal or Overlay at 15-25% opacity
  • Roblox Tip: Test on both flat and curved surfaces

3

Adding Random Scratches

Non-directional surface damage:

  • Add Fill Layer for scratches
  • Set content to "Crackle Noise" or "Gaussian Noise"
  • Add Black Mask
  • Optionally mask by curvature to focus on edges
  • Adjust scale, balance, and contrast
  • Set blending to Normal or Lighten at low opacity (5-15%)
  • Roblox Tip: Combine with curvature mask for edge-focused scratches

Organic Material Examples

Creating wood, fabric, and stone materials:

Wood Grain Material

1

Creating Wood Grain Pattern

Generate realistic wood grain:

  • Add Fill Layer for base color variation
  • Set content to "Perlin Noise" generator
  • Set scale to create grain-like features
  • Set offset to vary the pattern
  • Use anisotropic scaling (different X/Y scale) for grain direction
  • Adjust balance and contrast for subtle variation
  • Roblox Tip: Combine with gradient for heartwood/sapwood variation

2

Adding Wood Wear and Damage

Where wood shows use:

  • Add Fill Layer for wear (darker/lighter)
  • Add Black Mask
  • Generate mask using Curvature (for edges and corners)
  • Combine with Position (for high/low points)
  • Adjust mask parameters for desired wear placement
  • Set blending to Multiply or Overlay at appropriate opacity
  • Roblox Tip: Wood wear is often combination of edge wear and surface abrasion

3

Adding Knots and Imperfections

Natural wood characteristics:

  • Add Fill Layer for knot color variation
  • Add Black Mask
  • Use "From Mesh" generator if you have knot map
  • Or use Crackle Noise with specific parameters
  • Position knots where appropriate (not uniformly)
  • Roblox Tip: Knots should follow wood grain and be less frequent on visible faces

Fabric and Clothing Examples

Creating realistic fabric materials:

Woven Fabric Material

1

Creating Weave Pattern

Generate realistic fabric weave:

  • Add Fill Layer for base color
  • Set to solid color for base fabric
  • Add Fill Layer for weave variation
  • Set content to "Grid" generator
  • Set scale to create thread-sized features
  • Adjust thickness for thread width
  • Set blending to Overlay or Soft Light at low opacity
  • Roblox Tip: Vary scale for different fabric types (fine cotton vs coarse burlap)

2

Adding Fabric Wear and Fading

Where fabric shows use:

  • Add Fill Layer for wear/fading (lighter color)
  • Add Black Mask
  • Generate mask using Position (high points)
  • Combine with Curvature (for edges and folds)
  • Adjust parameters for natural wear placement
  • Set blending to Normal at 10-30% opacity
  • Roblox Tip: Think about where fabric would rub or stretch during use

3

Adding Stains and Spots

Where accidents happen:

  • Add Fill Layer for stain color
  • Add Black Mask
  • Use "User Grayscale" or import stain texture
  • Or use Crackle Noise with specific parameters for spots
  • Position stains randomly or in logical locations
  • Roblox Tip: Stains should look accidental, not patterned

Pro Tip: Create Generator Presets

Save time on frequently used setups:

  • Create a generator configuration you use frequently
  • Right-click the generator in Properties panel
  • Choose "Create Preset" or "Save as Preset"
  • Name it descriptively (e.g., "Edge Wear Curvature", "Fabric Weave Grid")
  • Save to your shelf for instant access
  • Now you can drag-and-drop these presets onto any layer or mask
