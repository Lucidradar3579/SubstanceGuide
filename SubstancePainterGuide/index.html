Step 5

Use SurfaceAppearance on MeshParts and test materials in Studio.

Must-Know Texture Checklist

  • Use a clean UV layout with readable island spacing.
  • Keep base color values believable under Roblox lighting.
  • Export normal maps in OpenGL style for proper lighting response.
  • Use roughness and metalness maps to control realism and performance.
  • Test final materials with Studio lighting and mobile-appropriate texture sizes.
  • Preserve readable detail without creating giant texture memory costs.
