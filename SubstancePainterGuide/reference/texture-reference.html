Texture Reference Library

Difficulty: Intermediate Time: 45 minutes Software: Substance 3D Painter Roblox Relevance: High

This comprehensive texture reference library provides you with ready-to-use texture maps, patterns, and details that you can import into Substance 3D Painter to accelerate your texturing workflow for Roblox assets. Each texture includes specific settings and usage recommendations.

How to Use This Library

These textures are designed to be imported as:

  • Fill Layers: For base colors and uniform properties
  • Generators: To create procedural patterns and effects
  • Masks: To control where effects appear
  • Paint Layers: For adding details and variations
  • Resources: As reference for creating your own textures

Base Color Textures

Solid Colors

Usage:

  • Base color fill layers
  • Material ID masks
  • Color variation layers

Settings:

  • Color Space: sRGB
  • Format: PNG
  • Resolution: 512x512 (scalable)

Gradient Maps

Usage:

  • Height maps for slopes
  • Mask gradients
  • Color variation
  • Procedural material blending

Settings:

  • Color Space: Linear (for data), sRGB (for color)
  • Format: PNG
  • Resolution: 1024x1024

Checker Patterns

Usage:

  • UV testing
  • Mask patterns
  • Procedural tiling
  • Generators for tiling effects

Settings:

  • Color Space: sRGB
  • Format: PNG
  • Resolution: 512x512
  • Pattern Size: 10px, 20px, 40px variants

Normal Map Textures

Flat Normal Map

Usage:

  • Flat surfaces
  • When no normal detail is needed
  • Base for adding details

Settings:

  • Color Space: Linear
  • Format: PNG
  • Resolution: 512x512
  • RGB Values: 127,127,255 (OpenGL)

Bump Map Normal

Usage:

  • Subtle surface details
  • Fabric weaves
  • Light scratches
  • Paper textures

Settings:

  • Color Space: Linear
  • Format: PNG
  • Resolution: 1024x1024
  • Strength: Low (10-20%)

Strong Normal Map

Usage:

  • Deep grooves
  • Brick and stone mortar
  • Wood grain
  • Metal plating and rivets

Settings:

  • Color Space: Linear
  • Format: PNG
  • Resolution: 1024x1024
  • Strength: High (60-100%)

  • Format: PNG

Roughness Variation

Settings:

  • Format: PNG
  • Resolution: 1024x1024

Edge Wear Roughness

Usage:

  • Simulating paint wear
  • Metal scratching and abrasion
  • Corner damage and chipping

Settings:

  • Color Space: Linear
  • Format: PNG
  • Resolution: 1024x1024
  • Pattern: Edge-focused with center smooth

Metalness Textures

Uniform Metalness

Usage:

Settings:

  • Resolution: 512x512

Usage:

  • Resolution: 1024x1024

Flat Height Map

  • Color Space: Linear
  • Format: PNG
  • Resolution: 512x512

Brick/Stone Height

Settings:

  • Format: PNG
  • Resolution: 1024x1024

Usage:

  • Color Space: Linear
  • Format: PNG
  • Resolution: 1024x1024
  • Depth: 0.01-0.1 units (subtle fabric detail)

Flat AO Map

Usage:

  • No ambient occlusion needed
  • Flat, evenly lit surfaces
  • Base for adding AO details

Settings:

  • Color Space: Linear
  • Format: PNG
  • Resolution: 512x512
  • Value: 255 (no occlusion)

Cavity AO

Usage:

Settings:

Directional AO

Usage:

  • Directional lighting simulation
  • One-sided occlusion

  • Complex geometry shadowing

Settings:

  • Color Space: Linear
  • Format: PNG
  • Resolution: 1024x1024
  • Values: Gradient-based occlusion

Special Purpose Textures

Curvature Map

Usage:

  • Edge highlighting
  • Wear and tear simulation
  • Procedural edge masks
  • Enhancing details in generators

Settings:

  • Color Space: Linear
  • Format: PNG
  • Resolution: 1024x1024
  • Values: Convex (peaks) and concave (valleys)

Position Map

Usage:

  • World-position based effects
  • Height-based color blending
  • Procedural texture blending

Settings:

  • Color Space: Linear
  • Format: PNG
  • Resolution: 1024x1024
  • Values: XYZ position encoded in RGB

Noise Textures

Usage:

  • Adding random variation
  • Breaking up repetitive patterns
  • Creating grunge and dirt
  • Procedural variation in generators

Settings:

  • Color Space: Linear
  • Format: PNG
  • Resolution: 512x512, 1024x1024
  • Types: Gaussian, Perlin, Worley, Value noise

Roblox-Specific Texture Settings

Recommended Export Settings for Roblox

Texture Type Color Space Format Bit Depth Compression Notes
Base Color sRGB PNG 8-bit None Use for Albedo/Base Color in SurfaceAppearance
Normal Map Linear PNG 8-bit None OpenGL format (Green: +Y up)
Roughness Linear PNG 8-bit None Invert if needed for your workflow
Metalness Linear PNG 8-bit None 0 = dielectric, 1 = conductor
Height/Displacement Linear PNG 8-bit or 16-bit None Use for detailed geometry simulation
Ambient Occlusion Linear PNG 8-bit None Multiply with lighting in shaders
Emissive sRGB PNG 8-bit None For glowing effects (use sparingly)
Opacity/Alpha Linear PNG 8-bit None 0 = transparent, 255 = opaque
