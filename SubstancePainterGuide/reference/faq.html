Frequently Asked Questions

Difficulty: Beginner Time: 20 minutes Software: Substance 3D Painter Roblox Relevance: High

This FAQ section addresses the most common questions about using Substance 3D Painter specifically for creating Roblox assets. Whether you're just getting started or you're an experienced artist, these answers will help you work more efficiently and avoid common pitfalls.

Do I need the latest version of Substance 3D Painter for Roblox workflow?

While you can use older versions, we recommend Substance 3D Painter 2020 or later for the best Roblox workflow. Newer versions include improved PBR workflow tools, better export options, and enhanced generator systems that are particularly useful for Roblox asset creation.

Is Substance 3D Painter difficult to learn for Roblox texturing?

Substance 3D Painter has a moderate learning curve, but the basics can be learned in a few hours. The layer-based system is intuitive for those familiar with Photoshop or similar tools. For Roblox specifically, focus on learning layers, generators, masks, and the export workflow - you don't need to master every feature to create great Roblox assets.

What's the minimum system requirement for running Substance 3D Painter?

Minimum requirements: 64-bit Windows 10, 8GB RAM (16GB recommended), DirectX 11 compatible GPU with 2GB VRAM (4GB recommended), and 10GB free disk space. For complex Roblox assets with high-resolution textures, we recommend 16GB RAM and a GPU with 4GB+ VRAM for smooth performance.

What's the typical workflow from Blender to Substance 3D Painter to Roblox?

The standard workflow is: 1) Model and UV unwrap in Blender, 2) Import FBX/OBJ into Substance 3D Painter, 3) Create textures using layers and generators, 4) Export texture maps (Base Color, Normal, Roughness, Metalness, etc.), 5) Import into Roblox Studio and assign to SurfaceAppearance on MeshPart objects.

Should I bake in Substance 3D Painter or use external baking tools?

Substance 3D Painter's built-in baker is excellent for most Roblox workflows and offers tight integration with the texturing process. Use external bakers (like Marmoset Toolbag or xNormal) only if you need specific features not available in Painter, or if you're working with extremely high-poly models that exceed Painter's capabilities.

How many texture sets should I use for a Roblox asset?

For optimal Roblox performance, use as few texture sets as possible - ideally just one. Multiple texture sets increase memory usage and draw calls. Only use multiple sets when absolutely necessary, such as for very large assets with radically different materials in different areas (like a character with clothing and skin).

What color space should I use when exporting textures for Roblox?

For Roblox: Base Color, Emissive, and Opacity maps should be exported in sRGB color space. Normal, Roughness, Metalness, Height, and Ambient Occlusion maps should be exported in Linear color space. This ensures correct interpretation in Roblox's rendering pipeline.

Do I need to flip the green channel in my normal maps for Roblox?

Roblox expects OpenGL format normal maps where the green channel represents +Y up. When creating a new project in Substance 3D Painter, make sure to select "OpenGL" as the normal map format. If you've already created your project, check your texture set settings and ensure the normal map format is set to OpenGL.

What file format should I export my textures as for Roblox?

PNG is the recommended format for Roblox textures because it's lossless and supports alpha channels. Roblox also accepts JPG, TGA, and BMP, but PNG provides the best quality without compression artifacts. Use 8-bit per channel for most textures; 16-bit is only needed for displacement maps requiring extreme precision.

What's the difference between regular Parts and MeshParts in Roblox?

Regular Parts are basic geometric shapes (blocks, spheres, cylinders, etc.) that don't support custom textures. MeshParts are custom mesh objects that can use SurfaceAppearance to apply custom textures created in Substance 3D Painter. Always use MeshPart objects when applying your Substance Painter textures in Roblox.

How do I create animated textures for Roblox using Substance 3D Painter?

Substance 3D Painter can create animated textures through animation tracks that export texture sequences. However, for Roblox, consider using flipbook animations (texture atlases) or scripting texture changes rather than true video textures, as Roblox has limited support for animated textures and they can be performance-intensive.

Can I use Substance 3D Painter materials directly in Roblox?

No, you cannot directly use .sbsar (Substance) files in Roblox. You need to export bitmap textures (PNG format) from Substance 3D Painter and then apply them to MeshPart objects using Roblox's SurfaceAppearance system. The .sbsar format is proprietary to Adobe's Substance ecosystem and isn't supported in Roblox.

What texture resolution should I use for mobile Roblox performance?

For mobile Roblox, we recommend 512x512 or smaller textures for most assets. Mobile devices have significantly lower texture memory limits than PC. Test your assets on target mobile devices and use Roblox's TextureService to monitor memory usage. Consider creating LOD versions with lower resolutions for mobile.

How can I reduce texture memory usage in my Roblox assets?

To reduce texture memory usage: 1) Use the smallest resolution that maintains visual quality, 2) Reuse textures across multiple parts of your asset, 3) Combine multiple textures into atlases when possible, 4) Use 8-bit textures instead of 16-bit where precision isn't needed, 5) Delete unused texture sets from your Substance Painter project, 6) Consider using texture compression where appropriate.

Do I need to worry about texture streaming in Roblox?

Yes, Roblox streams textures based on distance from the camera. Important details should remain visible even at lower mip levels. Avoid putting critical details only in high-frequency areas of your textures. Test your assets at various distances to ensure they stream well and maintain visual quality throughout the mip chain.

My textures look washed out in Roblox compared to Substance 3D Painter - what's wrong?

This is almost always a color space issue. Ensure your Base Color texture is exported in sRGB color space (not Linear). Also check that you haven't accidentally applied any color correction or grading in your export process. Verify that your normal map is in OpenGL format and that your roughness/metalness maps are in Linear color space.

Why does my normal map lighting look inverted in Roblox?

Inverted lighting usually means your normal map format is incorrect. Roblox expects OpenGL format (Green: +Y up). Check your Substance 3D Painter project settings when creating the project, or check the texture set settings for existing projects. Try flipping the green channel in your normal map if you suspect format issues.

My textures aren't showing up at all on my MeshPart in Roblox - what should I check?

Check these common issues: 1) Is your object actually a MeshPart (not a regular Part)? 2) Are you using SurfaceAppearance (not Texture)? 3) Are the texture file paths correct and accessible? 4) Are you using the correct texture slots (BaseColorMap, NormalMap, etc.)? 5) Are your texture file names exactly what you expect? 6) Do you have sufficient permissions to read the texture files?

Quick Tips for Success:

  • Start Simple: Begin with basic materials before attempting complex layered effects
  • Test Early: Import your textures into Roblox Studio frequently during creation
  • Keep Organized: Use clear naming conventions for your texture sets and layers
  • Learn the Basics: Master layers, generators, and masks before exploring advanced features
  • Optimize for Roblox: Always consider performance and platform limitations
  • Use References: Study real-world materials and how they behave under different lighting
  • Join Communities: The Roblox Developer Forum and Substance communities are great resources
