Roblox PBR Workflow in Substance 3D Painter

Difficulty: Beginner → Intermediate Time: 25 minutes Software: Substance 3D Painter Roblox Relevance: Essential

Understanding how Physically Based Rendering (PBR) works in Roblox and how to create textures that work perfectly with the Roblox engine is crucial for creating professional-quality assets. This guide will walk you through the Roblox PBR workflow, from setting up your Substance 3D Painter project to exporting textures that work seamlessly with Roblox's SurfaceAppearance system.

Why PBR Workflow Matters for Roblox

Roblox uses a Physically Based Rendering system that simulates how light interacts with materials in the real world. Creating textures that follow PBR principles ensures your assets look correct under all lighting conditions and maintain visual consistency across different Roblox experiences.

Understanding Roblox's PBR System

How Roblox implements Physically Based Rendering:

Roblox's PBR Implementation:

  • Uses Metallic-Roughness workflow (same as Substance 3D Painter default)
  • Base Color = Albedo color (diffuse reflectance)
  • Metalness = Whether material is metallic (0 = non-metal, 1 = metal)
  • Roughness = Surface microsmoothness (0 = smooth, 1 = rough)
  • Normal Map = Surface detail for lighting simulation
  • Key Difference: Roblox combines your AO map with its own SSAO

Roblox SurfaceAppearance Channels:

ColorMap

Base color/albedo of the material

Source: Base Color channel from Substance Painter

Format: sRGB color space

Format: PNG (lossless recommended)

MetalnessMap

Metallic property of the material

Source: Metalness channel from Substance Painter

Value: 0.0 = non-metal, 1.0 = metal

Format: Grayscale, linear color space

Format: PNG (lossless recommended)

RoughnessMap

Surface roughness/smoothness

Source: Roughness channel from Substance Painter

Value: 0.0 = smooth, 1.0 = rough

Format: Grayscale, linear color space

Format: PNG (lossless recommended)

NormalMap

Surface normal detail for lighting

Source: Normal channel from Substance Painter

Format: OpenGL format (Y axis may need inversion)

Roblox Tip: Test in Studio - lighting should look correct from above

Format: PNG (lossless essential for normals)

ColorMap (Alpha)

Transparency/opacity

Source: Alpha channel from Substance Painter

Value: 0.0 = transparent, 1.0 = opaque

Format: Grayscale, linear color space

Format: PNG (lossless recommended)

OcclusionMap

Ambient occlusion/contact shadowing

Source: Ambient Occlusion channel from Substance Painter

Note: Roblox combines this with its own SSAO

Format: Grayscale, linear color space

Format: PNG (lossless recommended)

Setting Up Your Substance Project for Roblox

Configuring Substance 3D Painter for optimal Roblox compatibility:

Project Configuration Steps

1

Color Management Settings

Ensure correct color spaces:

  • Edit > Settings > Color Management
  • Color Space: Set to "sRGB" for all texture types
  • Viewport Color Space: Set to "sRGB"
  • Export Color Space: Set to "sRGB" for Base Color, Emissive, and Opacity maps
  • Data Color Space: Set to "Linear" for Normal, Roughness, Metalness, Height, and Ambient Occlusion maps
  • Why: Roblox expects sRGB for color data and Linear for data maps
2

Default Project Settings

Set up efficient defaults:

  • Edit > Settings > Default Project
  • Document Resolution: Set to 2048 (good balance for most Roblox assets)
  • Document Size: 2048 x 2048 pixels
  • Default Preset: Choose "PBR Metallic Roughness"
  • Normal Map Format: OpenGL (matches Roblox expectation)
  • Why: 2048 resolution provides good detail while keeping file sizes manageable
3

Creating Your Project

Start with the right foundation:

  • File > New Project
  • Select your mesh (FBX, OBJ, etc.)
  • Keep resolution at 2048 (or adjust based on asset type)
  • Ensure "PBR Metallic Roughness" template is selected
  • Click "OK" to create the project
  • Tip: Verify your mesh has proper UVs and is scaled correctly (1 unit = 1 cm in Roblox)

Creating PBR-Compliant Materials

Creating materials that work correctly with Roblox's lighting:

Understanding PBR Values

Creating physically plausible materials:

Metalness Guidelines:

  • Should be 0.0 or 1.0 for most materials
  • Values in-between (0.1-0.9) are for mixed materials like rusted metal
  • Examples: Plastic=0.0, Wood=0.0, Glass=0.0, Metal=1.0, Rusted Metal=0.3-0.7

Roughness Guidelines:

  • 0.0-0.2: Very smooth (polished metal, glass, ice)
  • 0.2-0.5: Smooth to medium (unpolished metal, plastic, wood)
  • 0.5-0.8: Medium to rough (stone, concrete, unvarnished wood)
  • 0.8-1.0: Rough (fabric, burlap, coarse sand)
  • Tip: Use real-world references for accurate values

Color Guidelines:

  • Base color should represent true diffuse reflectance
  • For metals: Base color is the specular color
  • For non-metals: Base color is the diffuse color
  • Tip: Use color picking from reference photos under neutral lighting

Creating a PBR Material Step-by-Step

1

Establish Base PBR Properties

Set up your fundamental material properties:

  • Add Fill Layer for Base Color
  • Set to appropriate color (use eyedropper from reference)
  • Enable only Base Color channel
  • Add Fill Layer for Roughness
  • Set to appropriate grayscale value
  • Enable only Roughness channel
  • Add Fill Layer for Metalness
  • Set to appropriate grayscale value (0.0 or 1.0 for pure materials)
  • Enable only Metalness channel
2

Add Surface Detail

Create realistic surface variation:

  • Add Fill Layer or Paint Layer for base color variation
  • Use generators (noise, patterns) for subtle variation
  • Keep variation subtle - PBR materials should be mostly uniform
  • Tip: Use low opacity (10-30%) for variation layers
3

Add Wear and Damage

Where the material shows use:

  • Use masks to control where wear appears
  • Curvature mask for edge wear
  • Position mask for dirt in crevices
  • Combine masks for complex wear patterns
  • Adjust roughness and metalness where wear occurs
  • Tip: Wear should follow logical patterns based on use case
4

Add Surface Detail (Normal Map)

If you have/detail to add:

  • Either bake from high-poly mesh
  • Or use generators to create procedural normals
  • For most Roblox assets, subtle normal detail is sufficient
  • Tip: Don't overdo normal map strength - subtle is often better

Exporting Textures for Roblox

Getting your textures ready to use in Roblox Studio:

Export Configuration Steps

1

Choose Export Format

Select appropriate file formats:

  • Format: PNG (lossless, essential for normal maps)
  • Bit Depth: 8-bit is sufficient for most cases
  • Do NOT use JPEG for normal maps (artifact city)
  • Tip: Use PNG for all channels to ensure quality
2

Set Up Export Preset

Configure your export channels:

  • File > Export Textures
  • Click "+" to add export preset
  • Name it "Roblox PBR"
  • Configure channels:
    • Base Color → ColorMap.png
    • Metalness → MetalnessMap.png
    • Roughness → RoughnessMap.png
    • Normal → NormalMap.png
    • Ambient Occlusion → OcclusionMap.png
    • Opacity (if used) → ColorMap.png (alpha channel)
  • Set output format to PNG for all channels
  • Set color space:
    • sRGB for Base Color (and Occlusion if used as color)
    • Linear for Metalness, Roughness, Normal
  • Tip: Save this preset for reuse on all Roblox projects
3

Export Your Textures

Generate the final texture files:

  • Click "Export" button
  • Choose output folder
  • Substance will generate your texture files
  • Tip: Verify files were created correctly in output folder
4

Verify Texture Naming

Ensure files are named correctly for Roblox:

  • ColorMap.png (Base Color)
  • MetalnessMap.png (Metalness)
  • RoughnessMap.png (Roughness)
  • NormalMap.png (Normal)
  • OcclusionMap.png (Ambient Occlusion)
  • Tip: Roblox will automatically use these names if placed in correct folder

Testing in Roblox Studio

Verifying your textures work correctly in Roblox:

Testing Procedure

1

Import Textures into Roblox Studio

  • In Roblox Studio, select your Part or MeshPart
  • In Properties window, find SurfaceAppearance
  • If not present, add SurfaceAppearance component
  • Click each texture property and select your exported texture
  • ColorMap → ColorMap property
  • MetalnessMap → MetalnessMap property
  • RoughnessMap → RoughnessMap property
  • NormalMap → NormalMap property
  • OcclusionMap → OcclusionMap property
2

Test in Different Lighting

  • Change lighting environment in Studio
  • Test in Outdoor, Indoor, and custom lighting
  • Check that material looks correct in all conditions
  • Tip: Pay attention to how specular highlights look on metallic surfaces
3

Check for Common Issues

  • Too Dark/Light: Check Base Color values
  • Wrong Specular: Check Metalness and Roughness values
  • Flipped Normals: Check if lighting comes from wrong direction
  • Missing Details: Check if textures are properly connected
  • Seams or Stretching: Check UV layout and texture repetition
4

Iterate and Improve

  • Based on testing, go back to Substance Painter
  • Adjust values, masks, or details as needed
  • Re-export and re-test
  • Tip: Keep notes on what you changed for future reference
