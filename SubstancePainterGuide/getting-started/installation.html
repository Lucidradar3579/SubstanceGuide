Installation & Setup

Difficulty: Beginner Time: 15 minutes Software: Substance 3D Painter Roblox Relevance: Essential

Getting started with Substance 3D Painter is straightforward, but there are some important considerations for Roblox texturing that will save you time and frustration later. This guide will walk you through the installation process, initial setup, and configuration recommendations specifically for Roblox workflows.

Why This Matters for Roblox

Proper installation and setup ensures you're using the correct color spaces, texture resolutions, and export settings that work seamlessly with Roblox's rendering engine and SurfaceAppearance system.

System Requirements

Before installing Substance 3D Painter, ensure your system meets these requirements:

  • Operating System: Windows 10 (64-bit) or macOS 10.15+
  • Processor: Intel Core i5 or AMD equivalent (minimum)
  • Memory: 8 GB RAM minimum, 16 GB+ recommended
  • Graphics Card: Dedicated GPU with 2 GB VRAM minimum (NVIDIA GTX 1050 or better)
  • Storage: 10 GB free space for installation, plus additional space for texture projects
  • Display: 1920x1080 resolution minimum

Performance Note for Roblox Workflows

While Substance 3D Painter can run on minimum specifications, Roblox character texturing often involves working with multiple texture sets (2K-4K resolution) and complex smart materials. For optimal performance, we recommend:

  • 16 GB RAM or more
  • NVIDIA RTX 2060 or better GPU
  • SSD storage for faster project loading and saving

Download and Installation

Step-by-Step Installation Process

1

Download Substance 3D Painter

Visit the official Adobe Substance 3D website: substance3d.com

Click the "Free Trial" button if you don't have a subscription, or "Sign in" if you already have an Adobe ID.

Note: Adobe offers a 30-day free trial with full functionality.

2

Run the Installer

Once downloaded, run the installer (.exe for Windows, .dmg for macOS).

Follow the on-screen instructions:

  • Accept the license agreement
  • Choose installation directory (default is recommended)
  • Select additional components (Substance 3D Assets is recommended)
  • Click "Install"
3

Launch and Sign In

After installation completes, launch Substance 3D Painter.

Sign in with your Adobe ID to activate your trial or subscription.

If you don't have an Adobe ID, you'll need to create one (free).

4

Initial Configuration

On first launch, Substance 3D Painter will show a welcome screen. Take note of:

  • The location of the shelf (default libraries)
  • How to access the Asset Store (Window > Asset Store)
  • The default project location

Click "Get Started" to enter the main interface.

Roblox-Specific Setup Recommendations

After installation, configure these settings for optimal Roblox workflow:

Color Management Settings

Go to Edit > Settings > Color Management:

  • Color Space: Set to "sRGB" for all texture types
  • Viewport Color Space: Set to "sRGB"
  • Export Color Space: Set to "sRGB" for Base Color, Emissive, and Opacity maps
  • Data Color Space: Set to "Linear" for Normal, Roughness, Metalness, Height, and Ambient Occlusion maps

Why: Roblox expects sRGB for color data and Linear for data maps. Getting this right prevents color shifts when importing into Roblox.

Default Project Settings

Go to Edit > Settings > Default Project:

  • Document Resolution: Set to 2048 (good balance for most Roblox assets)
  • Document Size: 2048 x 2048 pixels
  • Default Preset: Choose "PBR Metallic Roughness"
  • Normal Map Format: OpenGL (DirectX if targeting specific engines that require it)

Why: 2048 resolution provides good detail for Roblox assets while keeping file sizes manageable. The PBR Metallic Roughness preset matches Roblox's SurfaceAppearance system.

Plugin and Shelf Setup

Consider installing these helpful plugins and organizing your shelf:

  • Substance 3D Assets: Install the basic materials pack for starting points
  • Custom Shelves: Create shelves for:
    • Roblox-specific smart materials
    • Character texture libraries
    • Material presets for common Roblox assets
    • Your custom textures and materials

Why: Organizing your library saves time and ensures consistency across your Roblox creations.

Verifying Your Installation

After installation, verify everything is working correctly:

Quick Verification Steps

1

Create a Test Project

File > New Project

Select a simple mesh (like a sphere or cube) for testing

Set resolution to 1024 (for quick testing)

Choose the "PBR Metallic Roughness" template

Click "OK"

2

Check the Interface

Verify you can see:

  • Viewport (3D view)
  • Layer Stack (usually right side)
  • Properties panel (when a layer is selected)
  • Toolbar (top)
  • Shelf (usually left side)
3

Test Basic Functionality

Try these quick tests:

  • Add a Fill Layer and change its color
  • Add a Paint Layer and try painting with the default brush
  • Add a Mask to a layer and generate a simple pattern
  • Try exporting textures (File > Export Textures)

If all these work, your installation is functioning correctly!
