Basic Texturing Workflow in Substance 3D Painter

Difficulty: Beginner Time: 30 minutes Software: Substance 3D Painter Roblox Relevance: Essential

Learning a solid basic workflow will give you the foundation to tackle any Roblox texturing project. This guide walks you through the essential steps from importing your model to exporting textures ready for Roblox.

Why a Consistent Workflow Matters for Roblox

Having a repeatable workflow ensures consistency across your Roblox assets, reduces errors, and makes collaboration easier when working with teams on Roblox projects.

Workflow Overview

The basic Substance 3D Painter workflow consists of these key stages:

Seven Steps to Textured Assets

1

Import and Setup

Getting your model into Substance Painter correctly:

  • File > New Project
  • Select your mesh (FBX, OBJ, etc.)
  • Choose appropriate document resolution (1K, 2K, 4K)
  • Select "PBR Metallic Roughness" template (matches Roblox)
  • Click "OK" to create the project
  • Roblox Tip: Ensure your model has proper UVs and is scaled correctly (1 unit = 1 cm in Roblox)

2

Bake Mesh Maps (If Needed)

Transfer high-poly details to your low-poly model:

  • Only needed if you have a high-poly source
  • Texture Set Settings > Bake Mesh Maps
  • Select high-poly mesh
  • Choose maps to bake (Normal, AO, Curvature, etc.)
  • Adjust settings (rays, distance, padding)
  • Click "Bake" to generate maps
  • Roblox Tip: For many Roblox assets, you can skip baking and use procedural details instead

3

Establish Base Materials

Setting up your foundational PBR values:

  • Add a Fill Layer for each channel (Base Color, Roughness, Metalness)
  • Set appropriate values for your material
  • Use grayscale values for Roughness (0= smooth, 1= rough)
  • Use 0-1 values for Metalness (0= non-metal, 1= metal)
  • Roblox Tip: Reference real-world PBR values for accuracy

4

Add Medium and Large Scale Details

Building up the main material characteristics:

  • Add Fill Layers or Paint Layers for patterns
  • Use generators for procedural details (noise, grunge, etc.)
  • Create masks to control where details appear
  • Examples: wood grain, fabric weave, metal plating patterns
  • Roblox Tip: Consider how details will read at a distance in Roblox experiences

5

Add Small Scale Details and Wear

Bringing your material to life with realistic details:

  • Add scratches, dents, dirt, and wear
  • Use smart masks (curvature, position, ambient occlusion)
  • Paint manually for unique character
  • Layer different wear types (scratches over dirt over paint chips)
  • Roblox Tip: Focus on details that will be visible in-game, not microscopic ones

6

Refine and Iterate

Checking your work and making improvements:

  • Toggle layers on/off to see their contribution
  • Check in different lighting environments
  • Compare to reference images
  • Adjust values and masks as needed
  • Keep your layer stack organized and labeled
7

Export Textures for Roblox

Getting your textures ready to use in Roblox Studio:

  • File > Export Textures
  • Choose export preset or create custom one
  • Select output format (PNG recommended)
  • Verify color spaces (sRGB for color, Linear for data)
  • Click "Export" to generate texture files
  • Roblox Tip: Name files clearly (BaseColor.png, Normal.png, etc.)

Detailed Walkthrough: Simple Prop Example

Let's walk through texturing a simple crate for Roblox:

Step-by-Step Crate Texturing

1

Project Setup

Start with a clean slate:

  • Import your crate FBX/OBJ
  • Use 1024 resolution (good balance for small props)
  • PBR Metallic Roughness template
  • No baking needed (low-poly only)

You should see your crate in the viewport with default gray material

2

Establish Base Wood Material

Create our wood foundation:

  • Add Fill Layer named "Base Wood Color"
  • Set Base Color to warm brown (#8B4513 or similar)
  • Add Fill Layer named "Wood Roughness"
  • Set Roughness to 0.3 (somewhat smooth wood)
  • Add Fill Layer named "Wood Metalness"
  • Set Metalness to 0.0 (wood is not metallic)

Your crate should now look like plain wood

3

Add Wood Grain Details

Make it look like real wood:

  • Add Fill Layer above base color
  • Set to "Wood" generator (or noise + gradient)
  • Add Black Mask
  • Generate mask using "Wood" generator
  • Set layer blending to "Overlay" at 30% opacity
  • Adjust generator parameters for grain direction

Now you should see subtle wood grain patterns

4

Add Wear and Damage

Give the crate history and use:

  • Add Fill Layer for scratches
  • Set color to slightly lighter than wood
  • Add Black Mask
  • Generate using Curvature + Noise
  • Set blending to "Normal" at 20% opacity
  • Add Fill Layer for dirt in crevices
  • Set color to dark brown
  • Add Black Mask
  • Generate using Ambient Occlusion
  • Set blending to "Multiply" at 15% opacity

Your crate now looks used and realistic

5

Final Checks and Export

Make sure it's ready for Roblox:

  • Check in different lighting (studio, outdoor, etc.)
  • Verify no seams or stretching in UV view
  • Ensure Normal Map looks correct (if baked)
  • Export as PNG textures
  • Name files: BaseColor.png, Normal.png, Roughness.png, Metalness.png

Workflow Tips for Different Roblox Asset Types

Adapt your approach based on what you're creating:

Characters and Avatars

Special considerations for wearable items:

  • Skin: Focus on subsurface scattering approximation, pore details, slight variation
  • Clothing: Fabric weave, thread count, seams, wear at stress points
  • Accessories: Material accuracy, branding, functional details
  • UV Considerations: Plan for symmetry, hide seams in less visible areas
  • Roblox Tip: Test textures on actual R15/Rthro avatars in various poses

Props and Environment Assets

For buildings, furniture, vehicles, etc.:

  • Scale: Larger assets can use lower texture densities
  • Repetition: Plan for tiling textures where appropriate
  • Lighting: Consider how asset will look in various Roblox lighting
  • Performance: Balance detail with texture size limits
  • Roblox Tip: Use tiling textures for large surfaces like walls or floors

UI and 2D Assets

For interfaces, icons, and 2D elements:

  • Resolution: Higher DPI needed for crisp UI
  • Pixel Perfect: Pay attention to hard edges and alignment
  • Transparency: Proper alpha channel handling
  • Consistency: Match style with other UI elements
  • Roblox Tip: Create UI at 2x intended size for better scaling

Common Beginner Mistakes to Avoid

Learn from others' pitfalls:

Mistake: Incorrect PBR Values

Problem: Materials look wrong in Roblox due to unrealistic values

Solution:

  • Reference real-world PBR charts
  • Metalness should be 0 or 1 (rarely in-between)
  • Roughness: 0-0.2 (very smooth), 0.2-0.5 (medium), 0.5-0.8 (rough), 0.8-1.0 (very rough)
  • Example: Polished metal = Roughness 0.1-0.3, Metalness 1.0

Mistake: Ignoring UV Layout

Problem: Stretching, seams, or inefficient texture use

Solution:

  • Check UVs in 3D software before importing
  • Use UV viewport mode in Substance to spot issues
  • Plan for adequate padding (2-4 pixels)
  • Consider UV island size relative to importance
  • Tip: Straighten UV islands and pack efficiently

Mistake: Overdoing Details

Problem: Assets look noisy or unrealistic due to excessive detail

Solution:

  • Start subtle, build up gradually
  • Reference real-world wear patterns
  • Consider viewing distance in-game
  • Use layers to control detail intensity
  • Tip: Toggle groups on/off to judge their contribution
