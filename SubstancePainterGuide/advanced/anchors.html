Mastering Anchor Points in Substance 3D Painter

Difficulty: Advanced Time: 30 minutes Software: Substance 3D Painter Roblox Relevance: High

Anchor Points are one of the most powerful features in Substance 3D Painter, allowing you to reference other texture maps within your project to create complex, dynamic materials. Understanding how to use Anchor Points effectively can dramatically improve your texturing workflow and enable you to create sophisticated materials that respond intelligently to your base textures. This guide will walk you through everything you need to know about Anchor Points, from basic concepts to advanced techniques, with practical examples for Roblox asset creation.

Why Anchor Points Matter for Roblox

Anchor Points enable you to create materials that adapt to your base textures, making your workflow more efficient and your results more sophisticated. For Roblox creation, this means you can create smart materials that automatically adjust to different base colors, create wear patterns that follow your geometry, and build complex layered materials that would be impossible to create manually.

Understanding Anchor Points

What Anchor Points are and how they work:

Anchor Point Fundamentals:

  • Definition: Anchor Points allow you to reference other texture maps (like Base Color, Normal, Height, etc.) as inputs to generators, filters, and effects
  • Purpose: Create materials that dynamically respond to your base textures
  • Benefits: Increased efficiency, dynamic material response, reduced manual work
  • Common Uses: Wear that follows curvature, dirt that accumulates in crevices, color variation that follows base color

Available Anchor Point Types:

What you can reference as Anchor Points:

  • Base Color: Reference the base color map
  • Height: Reference the height/displacement map
  • Normal: Reference the normal map
  • Ambient Occlusion: Reference the ambient occlusion map
  • Curvature: Reference the curvature map (convex/concave areas)
  • Position: Reference the position map (world or object space coordinates)
  • Thickness: Reference the thickness map (for mesh thickness)
  • Custom: Reference any other texture map in your project
  • Tip: Each Anchor Point type serves different texturing purposes

Basic Anchor Point Applications

Common uses for Anchor Points in material creation:

Using Curvature for Wear and Dirt

Creating wear that follows geometry:

Curvature Anchor Point Uses:

  • Positive curvature (convex areas): Edge wear, polishing
  • Negative curvature (concave areas): Dirt accumulation, grime, staining
  • Absolute curvature: Both convex and concave areas
  • Common in: Metal wear, paint chipping, dirt accumulation

Creating Curvature-Based Wear Step-by-Step

1

Set Up Your Base Material

Create your base material (metal, paint, plastic, etc.):

  • Base Color Fill Layer: Your base material color
  • Roughness Fill Layer: Base roughness value
  • Metalness Fill Layer: Base metalness value
2

Add Wear Layer with Curvature Anchor

Create wear that follows geometry:

  • Add Fill Layer for wear effect
  • Choose appropriate wear color/texture
  • In the layer's properties, find the "Anchor Point" setting
  • Set Anchor Point to "Curvature"
  • Adjust the "Anchor Point Level" to control wear intensity
  • Use a mask or generator to control where wear appears
  • Tip: Positive curvature for edge wear, negative for dirt in crevices
3

Refine the Wear Effect

Fine-tune your curvature-based wear:

  • Adjust Anchor Point Level for intensity
  • Use blur or sharpen to control wear falloff
  • Combine with other generators for complex wear patterns
  • Adjust layer blending mode and opacity
  • Tip: Test on different geometries to see how wear adapts
4

Final Adjustments

Complete your curvature-based wear material:

  • Adjust layer opacity and blending as needed
  • Consider adding multiple wear layers for complexity
  • Check how wear looks on different parts of your model
  • Tip: Save as a smart material for reuse on other projects

Using Position Anchor for World-Based Effects

Creating materials that respond to world coordinates:

Position Anchor Point Uses

What you can do with Position Anchor:

Position Anchor Point Applications:

  • Height-based effects (flood lines, snow accumulation)
  • Direction-based effects (wind erosion, rain streaks)
  • Procedural textures that follow world coordinates
  • Environmental effects that vary by position
  • Custom gradients based on object placement

Creating Height-Based Effects Step-by-Step

1

Set Up Your Base Material

Create your base material:

  • Base Color Fill Layer: Your base material color
  • Roughness Fill Layer: Base roughness value
  • Metalness Fill Layer: Base metalness value
2

Add Height-Based Effect with Position Anchor

Create effects that vary by height:

  • Add Fill Layer for the height-based effect
  • Choose appropriate effect (water line, snow, dirt, etc.)
  • In the layer's properties, find the "Anchor Point" setting
  • Set Anchor Point to "Position"
  • Configure Position Anchor settings (usually Y-axis for height)
  • Adjust the effect parameters to control height range
  • Tip: Position Anchor can use X, Y, or Z axes depending on your needs
3

Refine the Height-Based Effect

Fine-tune your Position Anchor effect:

  • Adjust Anchor Point settings for height range
  • Use gradients or curves to control effect falloff
  • Combine with masks to limit effect to specific areas
  • Adjust layer blending mode and opacity
  • Tip: Test with your model in different positions to verify effect
4

Final Adjustments

Complete your Position Anchor-based material:

  • Adjust layer opacity and blending as needed
  • Consider adding multiple height-based effects
  • Check how effect looks at different heights on your model
  • Tip: Save as a smart material for reuse on other projects

Using Base Color Anchor for Color-Adaptive Materials

Creating materials that adapt to base color changes:

Base Color Anchor Point Uses

What you can do with Base Color Anchor:

Base Color Anchor Point Applications:

  • Create wear that adapts to base color (lighter/darker wear)
  • Create color variations that follow base color shifts
  • Create effects that respond to base color brightness
  • Create materials that work with any base color
  • Build truly reusable smart materials

Creating Color-Adaptive Wear Step-by-Step

1

Set Up Your Base Material

Create your base material:

  • Base Color Fill Layer: Your base material color (this will vary)
  • Roughness Fill Layer: Base roughness value
  • Metalness Fill Layer: Base metalness value
2

Add Color-Adaptive Wear Layer

Create wear that adapts to base color:

  • Add Fill Layer for wear effect
  • Choose a neutral wear color (gray or brown)
  • In the layer's properties, find the "Anchor Point" setting
  • Set Anchor Point to "Base Color"
  • Use a gradient or color map to convert base color to wear intensity
  • Tip: Darker base colors can get lighter wear, lighter base colors can get darker wear
3

Refine the Color-Adaptive Effect

Fine-tune your Base Color Anchor effect:

  • Adjust Anchor Point settings for color sensitivity
  • Use curves or levels to control the color-to-effect mapping
  • Combine with other anchors (like Curvature) for complex effects
  • Adjust layer blending mode and opacity
  • Tip: Test with different base colors to verify adaptability
4

Final Adjustments

Complete your color-adaptive wear material:

  • Adjust layer opacity and blending as needed
  • Consider adding multiple adaptive layers
  • Check how wear adapts to different base colors
  • Tip: This creates truly reusable smart materials that work with any base color

Advanced Anchor Point Techniques

Combining Anchor Points for sophisticated effects:

Combining Multiple Anchor Points

Creating complex, responsive materials:

Advanced Anchor Point Combinations:

  • Curvature + Base Color: Wear that follows geometry and adapts to color
  • Position + Curvature: Height-based wear that follows geometry
  • Base Color + Position: Color effects that vary by height
  • Multiple Anchors: Create incredibly sophisticated, responsive materials

Creating Complex Wear with Multiple Anchors Step-by-Step

1

Set Up Your Base Material

Create your base material:

  • Base Color Fill Layer: Your base material color
  • Roughness Fill Layer: Base roughness value
  • Metalness Fill Layer: Base metalness value
2

Add Base Layer for Main Material

Establish your base material properties:

  • This is your primary material layer
  • Set up your base color, roughness, and metalness
  • This layer will be modified by the anchor-based effects
3

Add Curvature-Based Wear Layer

Create wear that follows geometry:

  • Add Fill Layer for curvature-based wear
  • Choose wear color/texture
  • Set Anchor Point to "Curvature"
  • Adjust for positive curvature (edge wear)
  • Set appropriate intensity and falloff
4

Add Base Color-Adaptive Layer

Make the wear adapt to base color:

  • Add Fill Layer for color adaptation
  • Use the wear layer from step 3 as base
  • Set Anchor Point to "Base Color"
  • Configure to make wear lighter/darker based on base color
  • This creates wear that adapts to the underlying base color
5

Add Position-Based Effect Layer

Add height-based variation to the wear:

  • Add Fill Layer for position-based effect
  • Choose effect (dirt accumulation, fading, etc.)
  • Set Anchor Point to "Position"
  • Configure for height-based effect (usually Y-axis)
  • This adds height-based variation to your curvature-based, color-adaptive wear
6

Refine and Balance the Effects

Fine-tune your multi-anchor material:

  • Adjust each anchor point layer's intensity and settings
  • Balance the contributions of each effect
  • Use layer masks to limit effects to specific areas if needed
  • Adjust blending modes and opacities for desired result
  • Tip: The key is subtlety - each effect should enhance, not overwhelm
7

Final Adjustments

Complete your complex multi-anchor material:

  • Check how the material responds to changes in base color, geometry, and position
  • Test on different parts of your model and different models
  • Tip: Save as a smart material for incredibly versatile reuse
