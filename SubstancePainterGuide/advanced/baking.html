Mastering Baking Techniques in Substance 3D Painter

Difficulty: Advanced Time: 45 minutes Software: Substance 3D Painter Roblox Relevance: High

Baking is the process of transferring high-detail information from a high-polygon model to a low-polygon model through texture maps. This technique is essential for creating game-ready assets that look highly detailed while maintaining performance. In Substance 3D Painter, baking allows you to capture intricate details like surface normals, curvature, ambient occlusion, and more, then apply them to your low-poly models for use in Roblox and other real-time engines.

Why Baking Matters for Roblox

Roblox has performance constraints that limit polygon counts. Baking allows you to create visually rich assets with detailed surface information baked into texture maps, rather than relying on high polygon counts. This enables you to create assets that look complex and detailed while remaining performant in Roblox experiences.

Understanding the Baking Process

How baking works and what it accomplishes:

Baking Fundamentals:

  • Purpose: Transfer high-poly detail to low-poly models
  • Input: High-poly model (source of detail) + Low-poly model (target)
  • Output: Texture maps (normal, AO, curvature, etc.)
  • Result: Low-poly model appears as detailed as high-poly when using baked maps
  • Performance: Dramatically reduces polygon count while preserving visual detail
  • Tip: Think of baking as "taking a picture" of your high-poly detail to apply to your low-poly model

Common Baked Map Types in Substance Painter:

What each map type captures:

  • Normal Map: Surface orientation and detail (most important)
  • World Space Normal: Normals in world space (useful for certain effects)
  • Curvature: Convex/concave surface information
  • Ambient Occlusion (AO): Shadowing in crevices and enclosed areas
  • Thickness: Volume information (thick vs thin areas)
  • Position: World position information
  • ID Map: Material/color identification for masking
  • Normals (Tangent Space): Standard normal map format
  • Tip: For Roblox, Normal Map and AO are most commonly used

Baking Requirements:

What you need for successful baking:

  • High-poly model with detailed geometry
  • Low-poly model (game-ready version)
  • Proper UV unwrapping on low-poly model
  • Models positioned correctly relative to each other
  • Appropriate cage settings (if using)
  • Tip: Models should share the same origin and be properly aligned

Setting Up for Successful Baking

Preparing your models and scene for baking:

Model Preparation

Getting your high-poly and low-poly models ready:

High-Poly Model Requirements:

  • Contains all the detail you want to capture
  • Can be sculpted, modeled, or procedurally generated
  • Does not need clean topology (for detail capture)
  • Should be manifold (no holes or non-manifold edges)
  • Tip: Use your sculpt or high-detail model as the high-poly

Low-Poly Model Requirements:

  • Game-ready topology with proper edge flow
  • Clean, manifold geometry
  • Properly unwrapped UVs (no overlaps, proper spacing)
  • Matches the silhouette of the high-poly model
  • Tip: Spend time on good UVs - they're crucial for baking quality

Scene Setup in Substance Painter

Configuring your project for baking:

Setting Up Your Baking Project Step-by-Step

1

Create New Project

Start your baking project:

  • File > New Project
  • Select your low-poly model as the mesh
  • Choose appropriate document resolution (2K, 4K, etc.)
  • Set up normal map format (usually OpenGL or DirectX)
  • Tip: For Roblox, OpenGL normal map format is commonly used
2

Import High-Poly Meshes

Add your high-poly detail sources:

  • Texture Set Settings > Import Meshes
  • Add your high-poly model(s)
  • Ensure they're properly positioned relative to low-poly
  • You can import multiple high-poly meshes for different parts
  • Tip: Name your high-poly meshes clearly for organization
3

Access Baker Settings

Open the baking configuration:

  • Go to Texture Set Settings
  • Click the "Bake" button or go to Bake menu
  • This opens the Baker window with all available map types
  • Tip: You can bake multiple maps simultaneously
4

Configure Baker Parameters

Set up your baking parameters:

  • Select which maps to bake (Normal, AO, Curvature, etc.)
  • Set output resolution (match your document resolution)
  • Set anti-aliasing (usually 4x or 8x for quality)
  • Set max tracing distance (important for proper ray casting)
  • Tip: Start with default settings, then adjust based on results
5

Set Up Cage (If Needed)

Configure the cage for problematic bakes:

  • The cage defines the ray casting distance
  • Use automatic cage generation first
  • If baking fails, manually adjust cage parameters
  • Frontal distance: rays cast outward from low-poly
  • Rear distance: rays cast inward toward low-poly
  • Tip: Proper cage settings eliminate most baking artifacts
6

Execute the Bake

Run your baking process:

  • Review all settings one final time
  • Click the "Bake" button to start processing
  • Wait for baking to complete (time varies with complexity)
  • Review the baked maps in the viewport
  • Tip: Bake a small test area first to verify settings
